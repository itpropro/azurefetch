# Security policy

## Supported versions

azurefetch is still pre-1.0, so security fixes only land in the latest release. Please check that the problem still exists there before you report it.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through GitHub instead:

https://github.com/itpropro/azurefetch/security/advisories/new

A useful report names the affected version and runtime (browser, worker, Bun, Deno or Node) and includes the steps or code that reproduce the issue. Replace real credentials, tokens and connection strings with placeholders.

You'll get a first response within 7 days. Once a fix is ready, I publish a release together with a GitHub security advisory that credits you, unless you'd rather stay anonymous.
