# Security policy

## Supported versions

azurefetch is still pre-1.0, so security fixes only go into the latest release. Please check that the problem still exists there before you report it.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through GitHub instead:

https://github.com/itpropro/azurefetch/security/advisories/new

Include the affected version and the steps or code that reproduce the issue. Name the runtime as well, for example Node, Bun, Deno, a browser or a worker. Replace real credentials, tokens and connection strings with placeholders.

You'll get a first response within 7 days. Once a fix is ready, I publish a release and a GitHub security advisory. The advisory credits you unless you'd rather stay anonymous.
